# Piyusha Wedanda — Portfolio

Personal portfolio showcasing web projects, skills, and contact information.

## About
This repository contains a single-page portfolio website built with HTML, CSS and JavaScript. It showcases projects, skills, education, and contact information for Piyusha Wedanda.

## Projects Highlights
- Flood Monitoring System — Python, React, MySQL, IoT
- ChannelMe — HTML, JavaScript, CSS, Bootstrap, PHP
- Class Management System — Java, MySQL, JavaFX
- Bank Management System — Java, Swing, Maven, MySQL, JDBC, JasperReports
- VPark — Kotlin, XML, Firebase, JavaScript
- Heart Disease Prediction — Python, Flask, Scikit-learn, React

## Technologies
HTML, CSS, JavaScript, Poppins (font), Canvas animations.

## View locally
1. Open the project folder:

```powershell
cd D:\PortfolioWeb
```
2. Open `piyusha-portfolio.html` in your browser, or rename it to `index.html` for GitHub Pages.

## Add to GitHub (quick commands)

```powershell
git add README.md
git add piyusha-portfolio.html
git commit -m "Add README and portfolio"
git push
```

If your remote isn't set yet, run:

```powershell
git remote add origin https://github.com/USERNAME/REPO.git
git branch -M main
git push -u origin main
```

## GitHub Pages
To publish the site, rename `piyusha-portfolio.html` to `index.html`, push, then enable Pages in the repository Settings → Pages → Branch: `main` → `/ (root)`.
